# AGENTS.md

Правила для AI-агента в этом проекте.

## Привычка: синхронизация с `PROGRESS.md`

В **конце каждой сессии**, перед прощанием, я обязан:

1. **Спросить пользователя**: «Что в backlog? Что планируем на следующую сессию?»
2. **Обновить `PROGRESS.md`**:
   - Перенести выполненные пункты из `## Следующие шаги (backlog)` в `## Лог` с датой
   - Добавить новые пункты в `## Следующие шаги (backlog)`
   - Обновить статус текущего этапа, если он изменился
3. **Если в ходе сессии всплыли новые концепции** (по которым пользователь задавал вопросы) — обновить соответствующий файл в `notes/`, **предварительно прочитав его**, чтобы не дублировать уже изложенное.

## Язык и стиль

- Отвечать на русском (пользователь пишет на русском)
- Не добавлять комментарии в код без явной просьбы
- Код — TypeScript-first, следуем существующему стилю проекта
